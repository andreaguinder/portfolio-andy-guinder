Otros proyectos

Context API

[ Ver proyecto ]

Esta aplicación es una tienda e-commerce interactiva de moda femenina desarrollada con React, Vite y Sass Modules. El objetivo principal de este trabajo práctico es implementar la Context API de React para compartir y consumir información de estado global en toda la aplicación, evitando el prop drilling y aplicando buenas prácticas de desarrollo, performance y arquitectura limpia.

  • Creación y Planificación del Contexto: Implementación de AuthContext en un archivo independiente dentro de src/context/ para gestionar la autenticación global.
  • Encapsulamiento con Provider: Creación del componente AuthProvider en el nivel adecuado de la aplicación para distribuir el estado global y sus funciones.
  • Consumo Eficiente: Uso del custom hook useAuth() para consumir el contexto desde múltiples componentes en distintas partes del árbol de la aplicación.
  • Optimización de Performance: Uso del hook useMemo en la definición del objeto value provisto por el contexto para evitar re-renders innecesarios.
  • Prueba Funcional y Manejo de Undefined: Validación explícita del consumo del contexto para lanzar un error descriptivo en caso de que un componente consumidor sea ejecutado fuera del AuthProvider.
